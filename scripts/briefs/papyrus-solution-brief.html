Product overview

Backoffice super­intelligence harness.

Papyrus by Beag Labs · Customer-hosted software

A deployable AI execution platform that enables organizations to automate complex back-office operations across existing systems of record using configurable data models, durable agents, human approvals, and governed workflows.

Your cloud / your data / your rules
The problem
01

Work lives between systems

Invoices, cases and approvals move across ERPs, inboxes, spreadsheets and terminals that were never designed to talk to each other.

02

Agents without a boundary

Most AI tools act from a vendor cloud, outside your identity, data and approval controls, with no record of why they acted.

03

Replacement is not an option

Systems of record carry years of configuration and policy. Rip-and-replace programs stall before they deliver.

What Papyrus does
01

Model

Classes define your own record types: entities, vendors, cases, assets, mapped to the systems that hold them.

02

Connect

Dynamics 365, NetSuite, Odoo, SharePoint and mainframes stay authoritative. Papyrus reaches them through scoped connections.

03

Execute

Durable agents and workflows run multi-step operations with checkpoints, retries, schedules and error handling.

04

Govern

Consequential actions pause for a human approval. Every action is recorded, so decisions can be reconstructed.

How it works

Model the business.
Run the work.

Papyrus pairs a configurable data model with durable agents. Agents understand what a vendor, an entity or a case is in your organization, then carry the work across the systems that hold it, stopping for people where policy says they must.

The platform
01

Classes

Your own record types with fields, relationships and source identities, created without code and kept in sync with connected systems.

02

Resources

One catalog of every record, file and ID across connected systems, so people and agents find the same thing the same way.

03

Factory apps

Describe a process and agents build the forms, dashboards and internal apps for it. Drafts publish only after review.

04

Workflows

A visual, top-to-bottom builder for triggers, branches, schedules and approvals. Agents can propose workflows for you to accept.

05

Durable agents

Long-running sessions with memory, schedules and signals that survive restarts. Model-independent by design.

06

Connectors

MCP-based, scoped tool access to external systems, with each connection tested and approved before it goes live.

Deployment + trust

Runs inside your boundary.

Papyrus is customer-hosted software. It ships as a hardened container that runs in your own cloud account or data center, signs people in with your Microsoft Entra tenant, and keeps your records where they already are.

Deployment options
01

Commercial

Self-serve from papyrus.beaglabs.com.

  • One-click deploy into your AWS account (Fargate on Graviton)
  • Microsoft sign-in connected in one step
  • 14-day trial, usage-based billing
  • Updates delivered as signed images
02

Government cloud

Deployed with our team.

  • GCC and GCC High Microsoft tenants
  • AWS GovCloud or Azure Government
  • Deployment profile set per environment
  • Runbook and customer-controlled handoff
03

DoD + disconnected

A dedicated DoD container.

  • DoD Microsoft cloud for sign-in and Graph
  • Signed offline license, verified locally
  • No callback to Beag Labs
  • Same features as commercial
Security controls
01

Entra-native identity

Microsoft Entra application roles are the only authority. No local accounts or separate role database.

02

Sandboxed execution

Agent code runs in a network-denied sandbox with filesystem isolation. Secrets come only from vault or managed identity.

03

Action ledger + approval

Every external action moves from proposal to human approval to ledger to executor before it happens.

04

Hash-chained audit

Integration and action events form an append-only SHA-256 chain, ready for review and incident response.

05

Signed licensing

Licenses are signed with an HSM-held key and verified inside the deployment, online or fully offline.

06

Hardened image

Built on Chainguard Wolfi, runs as non-root, ships with an SBOM, and is signed with Cosign on every release.

between systems.
